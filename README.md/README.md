# Sales Performance Dashboard | Microsoft Excel

## Project Overview

This project focuses on analysing sales performance using Microsoft Excel. The objective is to clean and analyse sales data, identify business trends, and develop an interactive dashboard to support data-driven decision-making.

## Business Problem

Retail businesses generate sales data across multiple products, customers, cities, and payment methods, making it challenging to monitor sales performance, identify revenue trends, and evaluate product performance manually.

This project addresses these challenges by developing an interactive Microsoft Excel dashboard that helps answer key business questions, including:

What are the total revenue, number of orders, quantity sold, and average order value?
Which products generate the highest revenue?
Why did March generate higher revenue than April, despite both months recording the same number of orders (12)?
Which cities contribute the most to total revenue?
Which payment methods generate the highest revenue?
How does monthly revenue change over time?
Which months record the highest and lowest sales?
How do completed, pending, and returned orders affect overall order performance?

## Data Cleaning & Transformation (Microsoft Excel)

Performed data cleaning and transformation in Microsoft Excel to prepare the sales dataset for analysis and dashboard development.

### Key Tasks

- Reviewed the original dataset to identify data quality issues.
- Checked for duplicate records and missing values.
- Removed leading and trailing spaces using TRIM.
- Standardized customer names and text values using PROPER.
- Corrected inconsistent text values using SUBSTITUTE.
- Used IF and IFS formulas to identify and flag data quality issues.
- Used VLOOKUP to validate customer IDs and product IDs against lookup tables.
- Checked for blank values using COUNTBLANK.
- Documented unresolved customer and product ID issues in the Data Quality Log.
- Prepared the cleaned dataset for PivotTable analysis.

## Key Findings

- January recorded the highest monthly revenue of ₹56,069.
- February recorded the highest number of orders (15).
- USB-C Hub generated the highest product revenue of ₹60,472.
- Delhi recorded the highest city revenue of ₹38,975.
- UPI generated the highest revenue among payment methods.
- Completed orders accounted for 69.39% of total orders, while pending and returned orders accounted for 16.33% and 14.29%, respectively.
- March generated higher revenue than April despite both months recording 12 orders.
- April recorded lower revenue, quantity sold, and Average Order Value compared with March.

## Business Recommendations

- Investigate the absence of April sales for products such as Desk Lamp, Laptop Stand, and Wireless Mouse.
- Monitor Average Order Value (AOV), particularly the decline recorded in April compared with March.
- Focus on high-revenue products such as USB-C Hub to sustain sales performance.
- Review sales opportunities for lower-revenue products such as Backpack.
- Follow up on the 8 pending orders and investigate the 7 returned orders.
- Monitor monthly revenue and quantity trends to identify changes in sales performance.
